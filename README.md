# 📱 RepTrack
| Layer | 📚 Technology Stack |
| ----- | -------------------- |
| Front-End | Expo |
| Components | Gluestack UI |
| Styling | Tailwind CSS |

## About
<p>This is a simple exercise logging app that features a clean, card-based interface where users can search through a list of exercises and log details such as exercise name, starting weight, sets, and reps.</p>

<p>The app uses state management to handle user input and updates along with AsyncStorage to persist data locally between sessions. </p>
